# Admin Dashboard – CSS Grid Project

This project is part of **The Odin Project – Intermediate HTML and CSS** curriculum.

## Project Description
A simple **Admin Dashboard layout** built using **HTML and CSS Grid**.  
The goal of this project is to practice:
- CSS Grid layouts
- Nested grids
- Sidebar, header, and main content structure
- Clean and readable HTML structure

## Built With
- HTML5
- CSS3 (Grid)
- Google Fonts (Roboto)

##  Features
- Sidebar navigation
- Header with search bar and user info
- Project cards section
- Announcements and trending section
- Clean dashboard-style UI
